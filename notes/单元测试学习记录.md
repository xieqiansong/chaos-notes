# 单元测试学习记录

工程依托：[jdk8-testing-demo](https://github.com/xieqiansong/chaos-java/tree/main/jdk8-platform/jdk8-testing-demo)（`chaos-java` 仓库，Mockito + Spring Boot 切片测试专项，5 个测试类各聚焦一个知识点，纯 Mockito mock 零外部依赖）。

> 注：本 demo 为讲解经典 Mockito 用法采用 JUnit 4（`@RunWith(MockitoJUnitRunner.class)`）；`chaos-java` 平台基线是 JUnit 5 + AssertJ + Mockito（见仓库 `AGENTS.md`），新代码请优先 JUnit 5（`@ExtendWith(MockitoExtension.class)`）。

## 1. 安装

```bash
cd jdk8-platform/jdk8-testing-demo
mvn test    # 无需启动外部服务，直接跑 *Test
```

测试框架：JUnit 4 + Mockito（`spring-boot-starter-test` 内置）；切片测试用 Spring Boot Test（`@WebMvcTest` + MockMvc）。

## 2. @Mock / @Spy / @InjectMocks

- `@Mock`：默认返回 null/empty；stub 后返回预设值。
- `@Spy`：部分真实 + 部分 mock。
- `@InjectMocks`：把 @Mock/@Spy 注入被测对象。
- 关键 API：`@RunWith(MockitoJUnitRunner.class)` 自动初始化注解。
- 坑：@Spy 下 stub 用 `doReturn().when()` 而非 `when().thenReturn()`（后者会先调真实方法）。

## 3. 参数匹配器

- `argThat` 自定义条件匹配；`any()` / `eq()` / `matches(regex)` 混用。
- 坑：**一旦使用 `any()`，所有参数都必须用匹配器**，具体值也要 `eq()` 包裹。

## 4. 行为验证

- `verify(mock, times(n))` / `never()` / `atLeast(n)` / `InOrder` 验证调用次数与顺序。
- 坑：`verify` 默认检查 exactly 1 次。

## 5. BDD 风格

- `BDDMockito.given()` / `BDDMockito.then()`，given-when-then 可读测试，跨角色沟通更顺。
- 坑：BDDMockito 只是 Mockito 的别名，功能完全一致。

## 6. @WebMvcTest 切片

- `MockMvc` 模拟 GET/POST 请求，验证状态码、响应体、JSON 路径，**只加载 Controller 层**，不启动整条链路。
- 关键 API：`mockMvc.perform()` + `andExpect()` + `jsonPath()`。

## 踩坑

- **@Spy stub 用 doReturn**：用 `when().thenReturn()` 会先执行真实方法，可能抛异常或产生副作用。
- **any() 传染所有参数**：混用具体值时必须 `eq()` 包起来，否则编译/运行报错。
- **verify 默认 exactlyOnce**：要验证多次/零次显式传 `times(n)` / `never()`。
- **切片测试别加载全容器**：`@WebMvcTest` 只加载 Web 层，@Repository/@Service 需 `@MockBean` 注入，保持测试快而纯。

## 进阶方向

- JUnit 5 迁移（`@ExtendWith` + `@Nested` + `@DisplayName`）。
- `@DataJpaTest` 数据层切片（H2 内存库）、Testcontainers 集成测试（真实 MySQL/Redis 容器）。
- WireMock 模拟外部 HTTP API、JaCoCo 覆盖率、Mutation Testing（PITest）。

# 性能优化模板

记录主动调优 / 压测 / 基准的实战。重点是**过程分析 + 量化对比**（延迟、吞吐、负载、精度），别只写"我优化了"然后没数据。参考 `performance/` 现有三篇（如《TCP-over-WebSocket 隧道：端到端性能基准与瓶颈分析》）。

## 模板

{开篇直接用口语讲：场景是什么、原来怎么做、瓶颈在哪。一两段说清楚，
  别上来就堆章节。}

## 现状与瓶颈

## 写作约定

- 语言：中文。
- **量化优先**：凡是结论都有数字支撑（吞吐、延迟、提升倍数），没有数据不下结论。
- **踩坑最有价值**：把真实踩过的坑展开写，别一句带过。
- **不要重复提炼**：表格后面只写表格里看不出的洞察，别把表又念一遍。
- **工程引用一律走 GitHub 链接**，不写本地相对路径。
- **发布前清理敏感信息**：日志、路径、内网 IP、账号、密码等一律脱敏或删减。
- 处于「整理中」的内容用「整理中」标注，不虚构已完成。
- 语气放开一点，像在给自己记笔记，不用端着写。

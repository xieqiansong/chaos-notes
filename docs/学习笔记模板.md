# 学习笔记模板

用于中间件/框架/语言（如 Go）等的学习记录。

## 定位与原则

- **完整、成体系**：一篇对应一个中间件/框架/语言，按「能力维度」全覆盖（参考范本：`chaos-java/jdk8-platform/jdk8-rocketmq-demo`，涵盖 acl/批量/广播/延时/顺序/事务/重试/过滤/幂等/限流/trace 等）。
- **以实战项目为载体**：笔记依托真实可运行的工程（demo），记录实现思路、关键代码、验证方式与踩坑过程，证明是亲手做出来的。
- **不重述官方文档**：官网已有的概论/概念不重复整理，只在自己实践基础上组织，必要时附官方链接作为参考来源。
- **可验证可运行**：关联工程 clone 可跑，命令/配置真实可达。
- **隐私合规**：不落库真实账号、密码、内网地址等敏感信息。每篇聚焦一个主题。

## 模板

```markdown
# {标题：中间件/框架/主题名}

## 版本与适用

- 中间件/框架版本：

## 要点

- 核心概念/配置/用法：

## 示例

- 关键示例代码或步骤：

## 参考来源

- （原文网址/关联项目）
```

## 写作约定

- 语言：中文。
- **注明适用的中间件/框架版本与参考来源**（原文网址），不搬运他人源码。
- **发布前清理敏感信息**：日志、路径、内网 IP、账号、密码等一律脱敏或删减。
- 处于「整理中」的内容用「整理中」标注，不虚构已完成。
